ICT BIG DAY 2026 — WINDOWS HOSTING

1. Extract the ZIP to a private folder on the Windows PC.
2. Open START-HERE.html for the complete instructions.
3. Install Node.js 24+ and cloudflared from their official download pages.
4. Run START-LOCAL.cmd and create your administrator.
5. For a temporary public test, close the local launcher and run START-TRIAL-LINK.cmd.
6. For event use, configure a fixed Cloudflare Tunnel in Host controls, then run START-LIVE.cmd.
7. After the public address passes its connection check, share the link/QR in the share folder.

Keep the hosting PC awake, online and the launcher open. No npm install is needed.
This package is a separate installation with a new database and email/password accounts.
Existing hosted-site data and ChatGPT accounts are not automatically transferred.
Read START-HERE.html before collecting real registrations.
