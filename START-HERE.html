Start here

This package is ready to install. It has not been installed or made live on your PC from this chat. Complete the steps below on the Windows PC that will host the event.

The PC needs Windows 10 or 11, Node.js 24 or newer, an internet connection and permission to run a local server. A public tunnel connects visitors securely to the server; you do not need to open a router port.

This is a separate installation with its own email/password accounts and a new registration database. The existing hosted website remains available. Its existing accounts, submissions and attendance are not automatically transferred. Choose one installation for registration so your counts stay together.

1. Install the two prerequisites

  1. Download and install Node.js 24 LTS or newer for Windows. The normal installer is sufficient. Close and reopen any Command Prompt windows afterwards.
  2. Open the official cloudflared download page. Download the Windows 64-bit executable for a standard Intel/AMD PC. Rename it cloudflared.exe and put it in this package’s tools folder. You can instead use the Windows MSI installer. Use an appropriate release for your PC’s architecture.
  3. Extract the entire ZIP to a folder you control, such as C:\ICT-Big-Day. Do not run it from inside the ZIP. Keep this folder private because it will hold accounts and submissions.

No passwords or tunnel tokens have been included in the download. You create them on your PC.

2. Create the administrator

  1. Double-click START-LOCAL.cmd. Keep its window open.
  2. The launcher opens a one-time setup link in your browser. If it does not, copy the setup link displayed in the window into your browser.
  3. Enter the event administrator’s name and email, then create a password of at least 12 characters. Use a unique passphrase and keep it safe.
  4. Host controls open at http://127.0.0.1:3000/host. Open the Organiser or Administrator workspace from there. The event website is http://127.0.0.1:3000.

The localhost address works only on the hosting PC. Give participants the public HTTPS address created in the next step.

3. Choose how to connect it

Quick test with a temporary link

  1. Close the local launcher with Ctrl+C. Run START-TRIAL-LINK.cmd.
  2. The launcher waits until the administrator is set up, starts a temporary Cloudflare tunnel, then checks that its HTTPS address reaches this installation.
  3. When the check succeeds, the window shows PUBLIC WEBSITE and saves your QR code in the share folder. Open share\SHARE.html to see the printable share page.
  4. Test the public link on a phone with Wi-Fi switched off, using mobile data. Create a test participant account, complete registration, then confirm the live counter updates on another screen.

Temporary links are for testing. They have no uptime guarantee, stop when the tunnel closes and change when you create a new tunnel. Do not print this QR on permanent event material. A new temporary link requires a new QR.

Fixed address for event registration

  1. Use a Cloudflare account and a domain managed on Cloudflare. If the university controls the intended address, ask its IT team to configure the hostname. The domain must be one you are authorised to use.
  2. Follow the current Cloudflare Tunnel setup guide. Create a remotely managed tunnel in the dashboard and select the Windows environment. This package launches cloudflared itself, so you do not need to install it as a Windows service.
  3. Add a published application route. Choose your real subdomain and domain. Set its service URL to http://127.0.0.1:3000. Leave the HTTP Host Header override unset so the public hostname reaches the app.
  4. Copy the tunnel token from the dashboard’s connector command. Copy only the token, not the whole command. Do not send it in chat or put it on the share page.
  5. With START-LOCAL.cmd running, open Host controls on the PC. Under Connect a fixed public address, enter your real HTTPS address and paste the token. Select Save fixed address.
  6. Close the launcher. Double-click START-LIVE.cmd. It starts the website and fixed tunnel, checks the public address and creates the QR code after a successful check.
  7. Test registration and sign-in from your phone using mobile data. You can now share the public address and its QR. Keep the PC, internet and launcher running.

The fixed address and QR stay the same across restarts as long as you keep that hostname. The website is reachable only while the PC and its tunnel are running. The launcher does not start automatically after a Windows reboot.

Registration and attendance

Visitors create an event account using their email and password, then complete event registration. Registration creates their entry code and counts them once. Updating a profile or reloading the website does not create extra registrations.

The live counter separates registered and checked in. Organisers enter the pass code for people arriving in person. Online participants confirm their own attendance after the organiser changes the event stage to live. The counter refreshes about every five seconds while a page is visible.

The original programme, all 22 activities and the corrected Ms Precious Leutle are included. The event date remains 23 October 2026; organisers control when the event becomes live.

Approved projects and accepted abstracts can be read by signed-in participants. Anonymous visitors see only published work whose author has consented to public display. Drafts, pending work, private scores and confidential review notes stay protected.

Back up your records

Run BACKUP-DATA.cmd regularly and before changing the installation. It creates a consistent SQLite database snapshot plus uploaded PDFs and hosting settings inside a timestamped backups folder. Copy that backup to a separate, private drive. It may contain the tunnel token and personal records.

To restore: stop the launcher, rename the current data folder, create a new empty data folder and copy the backed-up database, uploads and settings into it. Never combine old SQLite WAL/SHM files with the restored database. Restart the launcher and check the records.

If you forget the administrator password, keep the website running and double-click RECOVER-ADMIN.cmd on the hosting PC. It prints a private one-time password reset link. No account is recreated and attendance is retained.

If something does not connect

  • Node.js is missing: install Node.js 24 LTS or newer, then reopen the launcher.
  • cloudflared is missing: put the correct executable at tools\cloudflared.exe, or install the Windows MSI and reopen the launcher.
  • Port 3000 is already in use: close the other event launcher or the application using that port. Run only one copy against this data folder.
  • No public QR appears: the connection check did not pass. Confirm the internet connection, tunnel token, hostname and service URL. Restart the launcher after fixing them.
  • Temporary tunnel will not start: a pre-existing config.yml in your Windows user’s .cloudflared folder can prevent Quick Tunnels. Use the fixed tunnel or temporarily move that existing configuration only if you understand the other tunnel it belongs to.
  • The phone cannot open localhost: use the public HTTPS address, not 127.0.0.1 or localhost.
  • Connection blocked on university Wi-Fi: ask IT to permit outbound Cloudflare Tunnel traffic. Do not open router ports or change university network rules yourself.
  • Windows or organisation policy blocks a launcher: use a machine where running this system is permitted or ask your IT team. This package does not change execution policies.

Validation and limits

The portable server has passed automated checks for setup, authentication, permissions, unique attendance, public/private access, uploads, recovery and restart persistence. It includes the existing programme and conference workflows. The actual Windows launchers, physical PC, public tunnel and phone access must still be tested on your machine. No physical Windows or interactive browser test was available in the build environment.

Source files and third-party notices are included. The runtime needs Node.js but no package installation. To rebuild edited source, a developer can run npm install followed by npm run build in this folder. source contains the editable application and server; the main .mjs files and public\assets are prebuilt. Keep your existing data folder when updating application files.
